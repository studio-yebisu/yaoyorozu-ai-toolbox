text-to-cad での本来の流れと、この作例の範囲

  1. このページ寸法を決める外形・壁・底・内寸
  2. 提案のみPythonのモデルを書く@step(out=…) を付けた関数が build123d の形を返す（model-proposal.py、未実行）
  3. 未実行cadgen で STEP を書き出す環境が対応していれば python model-proposal.py で STEP/parts-case.step
  4. 未実行必要なら STL・3MF・GLBメッシュ用の装飾か、cadgen stl build
  5. 未実行スナップショットで形を確かめる書き出した STEP を画像にして自分で見る

このページで済んでいるのは上の2つだけです。3〜5は実行しておらず、STEP・STL・スナップショットはありません。text-to-cad はローカルで動くCADの手順（スキルとCLI）で、形を作るホスト型のAIサービスではありません。この作例でもAIサービスは使っていません。

実行する前に知っておくこと（上流の説明から）

  • 利用統計配布されるCADアプリ・ブラウザーのビューア・ビルドデーモンは、既定で利用統計を送ります（ファイル名・パス・中身・プロンプトは送らない、と上流は説明）。1つのプロセスだけ止めるなら DO_NOT_TRACK=1 または CADGEN_TELEMETRY=0。
  • 更新の確認cadgen は1日に1回まで新しい版を問い合わせます。CADGEN_UPDATE_CHECK=0 で止まります。
  • Windows のネイティブ部品CADカーネルの OCP は署名のないネイティブモジュールを含み、Windows 11 の安全機能に読み込みを止められることがある、と上流は書いています。この作例では安全設定を変えず、回避もしていません。
  • この作例で変えたものありません。環境変数・全体の設定・認証情報・インストールには触れていません。
